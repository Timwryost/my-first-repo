## Audio-to-Shape Demo

`pipeline.py` demonstrates a simplified version of the audio-to-physical-shape concept. It loads an audio file, computes a spectrogram, and uses placeholder functions to represent the physical sculpture and 3D scanning stages. Basic metrics are extracted from the data, mapped to a MIDI note, and written to a `.mid` file.

### Usage

```bash
python3 pipeline.py input.wav output.mid
```
